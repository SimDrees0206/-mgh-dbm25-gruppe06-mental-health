# -mgh-dbm25-gruppe06-mental-health
Analysis of a dataset on mental health among students at universities. Included: 1. Differences between male and female participants 2. Differences between the home and university environments in terms of perceived stress 3. Which factors explain the variance in stress levels 4. Identification of student types based on a cluster analysis. 
Original Link for the Dataset: https://data.mendeley.com/datasets/2gsjv8m7ch/2
